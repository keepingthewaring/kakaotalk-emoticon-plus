# KakaoTalk Emoticon Plus +

카카오톡 이모티콘 플러스 멤버십을 해제하고, 플러스 팩을 키보드 전체(ALL) 탭에서
바로 사용할 수 있게 해주는 Zygisk (Magisk/KernelSU) 모듈입니다.

`com.kakao.talk`만을 대상으로 동작하며, LSPosed나 별도의 설정 앱을
필요로 하지 않습니다.

## 크레딧

- [AmpleReVanced](https://github.com/AmpleReVanced/revanced-patches) — 이 모듈의 기반이 된 카카오톡 패치입니다
- [Pine](https://github.com/canyie/pine) — 런타임 후킹 프레임워크입니다

## 면책 조항

이 프로젝트는 카카오와 무관하며 개인 및 교육 목적으로만 제공됩니다.
사용으로 인해 발생하는 계정 제한, 정지, 데이터 손실 등 어떠한 피해에
대해서도 제작자는 책임을 지지 않습니다. 모든 사용 책임은 사용자 본인에게
있습니다.
